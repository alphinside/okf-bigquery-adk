# Corrections to the context bundle

Findings from implementation that contradict [the frozen bundle](./). Append, never edit. This is the return path to the upstream brainstorming workspace — a correction that stays in someone's head gets published as fact.

Worth recording: wrong API or class names, changed parameters, version drift, a claim that no longer holds, a step that cannot work as described, a cost that is not what was stated.
